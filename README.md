## GitHub Pages로 공개 주소 만들기 (약 5분)
1. GitHub에서 새 저장소 만들기 (예: `kimchajang`, Public)
2. 이 폴더의 파일을 모두 업로드 (Add file → Upload files)
3. Settings → Pages → Branch: `main` / `/ (root)` → Save
4. 1~2분 뒤 주소 생성: `https://<계정>.github.io/kimchajang/`
5. 그 주소로 QR을 다시 만들면 누구나(로그인 없이) 아이폰·갤럭시에서 바로 사용

## 공개 주소에서 추가로 되는 것
- 눈 건강 체크에서 실시간 카메라 미리보기 (HTTPS 필수 — GitHub Pages는 자동 HTTPS)
- 업비트 코인·환율 실시간 갱신, 위키백과 뜻풀이 검색
- 아이폰 Safari: 공유 버튼 → "홈 화면에 추가" → 앱 아이콘으로 전체 화면 실행
- 뉴스 검색: `kimchajang_search_server.gs`를 Google Apps Script로 배포 후 앱 ⚙ 설정에 URL 입력
